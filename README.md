# Project Manager - Тестовое задание

Проект представляет собой веб-приложение по управлению проектами и изображениями (с возможностью загрузки и выгрузки). 
Включает frontend на чистом JavaScript и backend на FastAPI с PostgreSQL.

### Использованные технологии:
- **Frontend**: Чистый JS + Bootstrap (без фреймворков для скорости)
- **Backend**: FastAPI + SQLAlchemy (быстрое прототипирование)
- **DataBase**: PostgreSQL (production-ready с Day 1)
- **Контейнеризация**: Docker Compose
- **Веб-сервер**: Nginx для статики



## Быстрый старт

### 1. Предварительные требования
- Docker 
- Docker Compose 
- Git

### 2. Клонирование и запуск

```bash
# 1. Клонировать репозиторий
git clone <repository-url>

# 2. Настроить переменные окружения
# создайте .env в корне проекта, на основе .env_template
cp .env_template .env
# Отредактируйте .env (укажите свои данные)

# 3. Запустить проект
docker-compose up --build

# 4. Или в фоновом режиме
docker-compose up -d --build
```

## PS
### Почему выбрана текущая архитектура:
- **Минимализм**: Фокус на основных требованиях ТЗ
- **Простота**: Легкость запуска и проверки


### Возможные улучшения
- S3/MinIO вместо локального хранилища - горизонтальное масштабирование файлов
- Микросервисы вместо монолита - разделение на проекты/изображения/аннотации
- Redis + Celery для асинхронных задач - обработка изображений и ML inference
- JWT аутентификация - безопасность и разделение прав

### Что не сделано (осознанно):
- Нет unit/integration тестов (можно добавить pytest + FastAPI TestClient)
- Нет CI/CD пайплайна
- Frontend - можно переписать на React/Vue при наличии должных навыков
